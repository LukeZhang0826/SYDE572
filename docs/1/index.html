Part 1: Shortest distance from a point to a function

Setup

For a point \((x_0, y_0)\) and a curve \(y = f(x)\), minimize the squared distance

$$D(x) = (x - x_0)^2 + (f(x) - y_0)^2$$

Analytical solution

$$D'(x) = 2(x - x_0) + 2\big(f(x) - y_0\big)f'(x) = 0$$

For \(y = x^2 + 5\) and points of the form \((x_0, 0)\), this becomes the cubic

$$2x^3 + 11x - x_0 = 0$$

Newton-Raphson

$$x_{k+1} = x_k - \frac{D'(x_k)}{D''(x_k)}, \qquad D''(x) = 2 + 2f'(x)^2 + 2\big(f(x) - y_0\big)f''(x)$$
